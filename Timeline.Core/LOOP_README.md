# Timeline 循环功能说明（小白版）

本文说明本仓库在 **Timeline** 上新增的「按 Tag 循环」相关功能：怎么用、注意什么、和普通时间轴的关系。

---

## 一句话理解

- **普通轨道**：仍然按时间轴主进度播放（从头到尾一条时间线）。
- **带 Tag 的业务轨道**：在「循环生效」的时间段里，只在 **`[from, to]`** 这段内容里来回采样，看起来像在循环播放。
- **四条专用配置轨**：不驱动角色/物体，只用来标记「循环从哪到哪、何时开始/结束」。

---

## 需要用到的轨道

在 Timeline 里添加以下内置轨（名称可能类似）：

| 配置轨 | 作用 |
|--------|------|
| **Loop From (tag)** | 某个循环的**起点**（关键帧的值 = Tag 名） |
| **Loop To (tag)** | 同一 Tag 的**终点** |
| **Loop Stat (tag)** | 从这一刻开始，该 Tag **进入循环** |
| **Loop End (tag)** | 从这一刻起，该 Tag **退出循环**（没有则一直循环到时间轴结束） |

同一 Tag **只允许一对** From / To；多个会报错并视为无效。

---

## 推荐操作步骤（第一次）

### 1. 给业务轨打 Tag

1. 右键一条要循环的业务轨（例如姿势、位移）。
2. 选 **Edit Tags...** 或 **Add Tag...**，输入名字，例如 `idle`。
3. 可多选多条轨一起加同一个 Tag。

轨名后面可能会显示：`轨道名 [idle]`。

### 2. 配置循环区间

1. 添加 **Loop From / Loop To** 轨。
2. 在时间轴上打关键帧。
3. **选中关键帧**，在打开的 **Keyframe 窗口**里用 Tag 按钮选择 `idle`（不能手打，只能选已有 Tag）。
4. From 时间 < To 时间，中间就是「循环内容」。

### 3. 配置何时循环

1. 添加 **Loop Stat / Loop End**，关键帧同样选 Tag `idle`。
2. 播放头在 Stat～End 之间时，带 `idle` 的业务轨走循环；之外按普通时间播。

### 4. 播放检查

- 主速度（Speed）一般为 **1** 时，循环段观感应接近「直接播放 From～To 那一段」。
- 若场景里有 **timeScale** 轨，且关键帧落在 From～To 内，循环内的快慢会跟这条轨（含曲线）走。

## 右键菜单相关功能

在业务轨上右键常见项：

| 菜单 | 说明 |
|------|------|
| **Edit Tags / Add Tag / Remove Tag / Clear Tags** | 管理轨上的 Tag 列表 |
| **Select Tracks With Tag** | 一键选中**所有**带该 Tag 的业务轨 |
| **Bake Loop To Keyframes** | 把循环「展开」成普通关键帧（见下） |
| 分组上的批量加 Tag 等 | 对一组轨批量操作 |

**Keyframe 窗口（选中配置轨关键帧时）**

- 下方会出现 Tag 按钮（Clear / 各 Tag 名）。
- **Use Current Value** 可在已有 Tag 之间切换。

## 循环怎么算时间？（概念）

1. 主时间轴走到 `T`。
2. 若该轨的 Tag 在 `T` 处于 Stat～End 激活状态：
   - 用主轴上的时间进度（会受 **Speed / timeScale 轨** 影响）；
   - 映射进 `[from, to]` 里的相位；
   - **只使用**落在 `[from, to]` 内的关键帧做插值。
3. 多条 Tag 同时激活在同一轨上 → **冲突**：该帧不按循环，回退普通主时间（并打日志）。

性能说明：没有复杂 timeScale 曲线时，计算很轻；只有变速率 timeScale 时才会用更细的积分。

## 烘焙（Bake）：做成「普通卡」也能播

**目的**：别人用**不带循环逻辑**的 Timeline 打开你的场景，仍能看到循环那段效果。

**做法**：按某个 Tag，把循环内容按规则**复制**到 Stat～End 的主时间上（不加密帧，只复制 From～To 里已有关键帧的副本）。

### 怎么用

1. 建议先 **保存场景**（烘焙也会尝试写 timeline 缓冲）。
2. 右键轨 → **Bake Loop To Keyframes** → 选 Tag。
3. 看日志里**一条总结**（成功/跳过数量等）。

### 规则摘要

- 只展开 `[from, to]` 内的源关键帧；曲线原样复制。
- 目标时间已有关键帧 → **不覆盖，跳过**。
- 多 Tag 冲突的轨 → **跳过**。
- **不删除**任何 Loop 配置和 Tag（方便兼容；旧 Timeline 会忽略这些配置）。
- 无 Loop End 时，展开到时间轴 **总时长**。

> 注意：若对方也是带循环的新版 Timeline，且 Tag 仍在，可能会「再循环一次」。给别人「纯普通卡」时可再手动去掉 Tag，或只用烘焙后的关键帧。

---

## 保存与兼容

- Tag 存在每条轨上，和 Timeline 一起写进场景扩展数据。
- 配置轨关键帧的值为 Tag 字符串。
- **旧版 / 普通 Timeline**：读关键帧仍可播；不认识 Loop 轨和 Tag 时一般无效果、不应整卡损坏。
- 新功能依赖本仓库编译出的 Timeline 插件。

## 常见问题

**Q：右键关键帧没有 Tag 列表？**  
A：请在 **Keyframe 窗口**里选 Tag；并先给业务轨配置过 Tag。只能在 **Loop From/To/Stat/End** 的关键帧上设 Tag。

**Q：循环不生效？**  
检查：业务轨是否有 Tag；From/To/Stat 是否齐全且 Tag 一致；是否 From&lt;To；是否多 Tag 冲突。

**Q：循环比 From～To 原速慢？**  
主 Speed 尽量为 1；看 From～To 内是否有 timeScale 关键帧；确认插件为当前版本。

**Q：日志在哪？**  
BepInEx 控制台 / 日志文件中查找以 `[Loop]` 开头的行。

## 功能一览（至今）

1. 四条 Loop 配置轨（From / To / Stat / End）+ Tag  
2. 业务轨 Tag 列表（仅轨上配置，关键帧只能选）  
3. 循环采样：主进度 + `[from,to]` 内 timeScale（含曲线）  
4. 冲突检测、性能快路径  
5. 按 Tag 全选轨道  
6. 烘焙为普通关键帧（保留 Loop 数据）  
7. 分组批量 Tag 等编辑辅助
